アプリ紹介

QBナビィ！でできることを、ひとつずつ紹介します。

EFFECT

画面を彩る演出(アフターエフェクト版機能)

戦闘中のダメージやクリティカル、Wave間のリザルトに合わせて、吹き出しや画面全体の演出を重ねて表示します。

  • 曲名の吹き出しやクリティカルの吹き出しを表示
  • 形・位置・透過度を設定ウィンドウで調整
  • 「そのほかの場面」も個別にオン・オフ
画面イメージ準備中
GAME INFO

ゲーム情報でプレイをサポート

ゲームから得られる情報をもとに、プレイ中に役立つ表示でサポートします。

  • ダメージやクリティカルの情報を読み取って表示
  • 敵のおおよその位置を推定して知らせる
  • Wave間のリザルトを自動で表示
PLAYER

動画・音楽・TVプレーヤー

ゲームをしながら、YouTube・音楽・TVをアプリの中で楽しめます。

  • ニュース・ライブ・ゲーム・アニメ・料理・音楽・動物のジャンル
  • 好きなチャンネルのURLを登録して自動再生
  • 窓を分離・合体、背景を透過、位置を固定
RECORD

記録とカレンダー

その日のキル数とスコアを記録します。獲得した武器は自動的に記録されるので、手で入力する必要はありません。

  • 獲得した武器を自動で記録し、累計で一覧
  • カレンダーに日ごとのキル数とスコアを表示
  • 今日と明日の天気をカレンダーの上に表示
SAVE

設定のまとめ保存

凝った設定は、まとめてファイルに保存できます。

  • 設定1・2・3をまとめて保存・読み込み
  • 別のパソコンへの引っ越しにも便利
